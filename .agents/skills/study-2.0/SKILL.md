# Study 2.0 — Antigravity 2.0 Study Session

Start or resume a structured study session for Antigravity 2.0.

## Steps

1. Read `2.0/STUDY_PLAN.md` and identify the first unchecked module (`[ ]`).

2. If all modules are checked, congratulate the user and suggest reviewing `meta/surface-comparison.md` or starting another surface.

3. For the current unchecked module:
   - Read the corresponding section in `2.0/mastering-guide.md`
   - Teach the concept: explain the "why" first, then the "how"
   - Highlight differences from the CLI when relevant (consult `meta/surface-comparison.md`)
   - Provide a practical example or usage scenario
   - Ask 1-2 verification questions

4. After the user confirms understanding:
   - Mark the module as `[x]` in `2.0/STUDY_PLAN.md`
   - Ask: "Quer continuar com o próximo módulo ou encerrar por hoje?"

5. If continuing, repeat from step 1.
