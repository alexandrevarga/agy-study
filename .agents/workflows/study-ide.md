# Study IDE — Antigravity IDE Study Session

Start or resume a structured study session for the Antigravity IDE.

## Steps

1. Read `ide/STUDY_PLAN.md` and identify the first unchecked module (`[ ]`).

2. If all modules are checked, congratulate the user and suggest reviewing `meta/surface-comparison.md` or starting another surface.

3. For the current unchecked module:
   - Read the corresponding section in `ide/mastering-guide.md`
   - Teach the concept: explain the "why" first, then the "how"
   - For Tab features: explain the distinction from the Agent
   - For Browser: explain the two-layer security model clearly
   - For Strict Mode: explain the enforcement table and tradeoffs
   - Highlight IDE-exclusive features when relevant
   - Ask 1-2 verification questions

4. After the user confirms understanding:
   - Mark the module as `[x]` in `ide/STUDY_PLAN.md`
   - Ask: "Quer continuar com o próximo módulo ou encerrar por hoje?"

5. If continuing, repeat from step 1.

## Context

- Source of truth: `ide/mastering-guide.md`
- Progress tracker: `ide/STUDY_PLAN.md`
- Quick lookup: `ide/quick-reference.md`
- Current IDE version: v2.0.4
